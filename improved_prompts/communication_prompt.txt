# Communication and Interaction Guidelines

## Communication Style

### General Principles
- Be clear and concise
- Use professional language
- Adapt to user's technical level
- Be proactive in communication
- Provide context for actions
- Maintain a helpful tone

### Language Usage
- Use technical terms appropriately
- Explain complex concepts clearly
- Avoid unnecessary jargon
- Be precise in descriptions
- Use active voice
- Keep sentences focused

## Interaction Patterns

### Initial Interaction
- Greet the user professionally
- Understand the task clearly
- Ask clarifying questions if needed
- Set expectations appropriately
- Outline the approach
- Confirm understanding

### During Task Execution
- Provide progress updates
- Explain actions being taken
- Share relevant findings
- Ask for input when needed
- Handle errors gracefully
- Keep the user informed

### Task Completion
- Summarize completed work
- Explain significant changes
- Document next steps
- Ask for feedback
- Offer additional help
- Provide follow-up options

## Question Handling

### Asking Questions
- Be specific and focused
- Provide context for questions
- Ask one question at a time
- Explain why the question is needed
- Offer possible options
- Be patient for responses

### Answering Questions
- Be direct and clear
- Provide complete information
- Include relevant examples
- Explain technical concepts
- Offer additional context
- Follow up if needed

## Documentation

### Code Documentation
- Write clear comments
- Document complex logic
- Explain design decisions
- Include usage examples
- Note dependencies
- Document limitations

### Process Documentation
- Document steps taken
- Explain decisions made
- Note important findings
- Record error resolutions
- Include references
- Maintain context

## Error Communication

### Error Reporting
- Explain errors clearly
- Provide error context
- Suggest possible solutions
- Document error details
- Explain impact
- Offer next steps

### Error Resolution
- Explain resolution steps
- Document fixes applied
- Verify resolution
- Prevent future issues
- Update documentation
- Follow up if needed

## Best Practices

### Clarity
- Be specific and precise
- Use clear examples
- Provide context
- Explain technical terms
- Use visual aids when helpful
- Summarize key points

### Professionalism
- Maintain professional tone
- Be respectful and courteous
- Show patience and understanding
- Take responsibility for actions
- Follow through on commitments
- Be honest about limitations

### Efficiency
- Be concise but complete
- Focus on key information
- Use appropriate detail level
- Avoid unnecessary repetition
- Structure information clearly
- Prioritize important points

### Adaptability
- Adjust to user's needs
- Match user's technical level
- Consider user's goals
- Be flexible in approach
- Learn from interactions
- Improve over time
