# Improved AI Coding Assistant Prompts

This directory contains a set of improved prompts for AI coding assistants, designed to enhance their effectiveness in helping users with programming tasks. These prompts incorporate the best elements from various existing AI assistant prompts while adding new improvements and best practices.

## Prompt Structure

The prompts are organized into four main components:

1. **Base Prompt** (`base_prompt.txt`)
   - Defines core identity and capabilities
   - Establishes personality traits
   - Sets working methodology
   - Outlines limitations and best practices

2. **Tool Usage Prompt** (`tool_usage_prompt.txt`)
   - Guidelines for using tools effectively
   - Code editing best practices
   - File operation procedures
   - Search and navigation strategies
   - Error handling approaches

3. **Communication Prompt** (`communication_prompt.txt`)
   - Communication style guidelines
   - Interaction patterns
   - Question handling procedures
   - Documentation standards
   - Error communication protocols

4. **Task Planning Prompt** (`task_planning_prompt.txt`)
   - Task analysis procedures
   - Planning process guidelines
   - Execution strategies
   - Completion protocols
   - Continuous improvement practices
